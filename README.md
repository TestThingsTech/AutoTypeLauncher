# AutoType Launcher

AutoType Launcher is a small Windows desktop utility that sends text to the active window after a short countdown.

Highlight a portion of the active tab to send only that selection. Otherwise, the entire active tab is sent. `F6` starts sending by default while the app is focused; choose `F7` through `F12` in the app if preferred.

## Download

Download `AutoTypeLauncher.exe` from the [latest release](https://github.com/TestThingsTech/AutoTypeLauncher/releases/latest) and run it directly.

No Python installation is required. Always start the app through `AutoTypeLauncher.exe`. It checks the latest GitHub Release, verifies the app download against its published SHA-256 checksum, installs it under your local app-data folder, and then starts the app.
